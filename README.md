# Quick Translate

个人使用的轻量 macOS 划词翻译工具：选中英文，按快捷键，在浮窗对照原文与中文译文，点击窗口外自动关闭。使用自己的阿里云大模型 API，通过 OpenAI 兼容接口请求翻译，不设置应用侧每日次数限制。
