## 目标和范围

交付一个可在本机启动的菜单栏应用，用户可以打开设置，保存服务地址、模型和 API Key，退出重启后配置仍然可用。完成 F01 的服务配置部分，对应 A01 和 A14 的配置隐私部分。

包含：实际工程、入口组装、菜单栏、设置窗口、退出操作、配置校验、项目 `.env` 文件存储，以及对应测试入口。

不包含：读取剪贴板、注册翻译快捷键、调用模型和翻译浮窗。快捷键设置由 T002 连同实际注册行为交付；本任务不显示可执行翻译或“快捷键已启用”的入口。

## 环境和实施内容

1. 核实本机 macOS、芯片、Xcode 与 Swift 工具链，选择最低支持版本与本次构建架构；在任务和开发规范中记录真实值，不把本机测试推断为所有版本通过。

4. 保存失败时准确提示；部分存储失败不能显示整体成功，也不能破坏此前可用配置。重启可恢复已确认保存的配置。

## 接口约定

以下为实现契约，具体 Swift 声明在编码前补入记录。

- 配置读取返回有效配置、未配置或明确错误，对象的调试描述不包含 API Key。
- 配置接口提供读取与原子保存 `.env` 的能力；测试使用独立临时目录，不读取或清除用户已有密钥。
- 配置保存校验必填项及 HTTPS 地址；对模型可用性的验证留给真实接入，不能将格式校验成功提示为“连接成功”。
- 配置与凭据依赖由应用入口注入；退出时释放本任务创建的窗口及资源。
- 若配置结构需要版本字段，记录初始版本和未来迁移策略；不为翻译历史建立数据存储。
