# Quick Translate 需求文档

版本：v0.1。日期：2026-11-08。阶段：需求与验收定义，尚未实现。

Quick Translate 是供个人使用的轻量 macOS 翻译工具。用户在其他应用中选中英文，按全局快捷键，即可在浮窗对照阅读原文与中文译文；点击浮窗外部后返回阅读。翻译通过用户自己的阿里云大模型 API 完成，采用 OpenAI 兼容的调用方式，工具不设置每日次数限制。

## 用户目标和已确认决定

| 项目 | 已确认要求 |
| --- | --- |
| 使用场景 | 阅读英文时快速获得中文翻译 |
| 触发方式 | 鼠标选中文字后按全局快捷键 |
| 选区获取 | 模拟复制并读取剪贴板，允许覆盖原有剪贴板内容，不做备份恢复 |
| 应用范围 | 面向能正常选中文字并通过 `⌘C` 复制文本的应用，不设置应用白名单 |
| 模型服务 | 阿里云 API，采用 OpenAI 兼容接口；用户尚未配置 API |
| 展示方式 | 同时显示原文与译文，方便对照 |
| 关闭方式 | 鼠标点击浮窗外任意区域自动关闭，不要求主动点叉或按 Esc |
| 产品取舍 | 轻量、专注翻译，不增加每日次数限制 |

下文中的配置、异常处理与验收细节为落实上述需求的产品定义。技术讨论后的实现方向为 Swift 原生 macOS 应用，结合 SwiftUI 和 AppKit，详见 [M002 任务规划](tasks/milestones/M002.md)。具体模型、服务地域、默认快捷键、最低 macOS 版本、芯片支持范围和工具链版本在开发准备阶段确定，不将其描述为已由用户选定。

## 第一版范围

包含菜单栏入口、API 设置、全局快捷键、复制选区、英文到简体中文翻译、原译文浮窗、复制译文、窗口外点击关闭，以及必要的加载和失败提示。

不包含 OCR、截图翻译、语音、词典、背单词、历史记录、账号系统、多引擎对照、其他平台客户端和云端同步。不建设业务服务端，客户端直接请求用户配置的模型服务。开机启动、应用商店上架、自动更新与公开分发不属于第一版验收。

图片文字、无法选中的扫描版 PDF 和禁止复制的内容不属于文本选区能力。兼容目标覆盖所有可复制文本的应用，但只能对实际验证的应用和版本给出通过结论，不承诺尚未验证的全部应用均可用。

## 用户流程

首次打开后，用户从菜单栏进入设置，填写 API Key，选择或填写模型，并确认接口地址。需要系统权限时说明用途并提供前往设置的入口；不在用户未主动翻译时读取剪贴板或发送选区。

日常操作如下：

1. 在当前应用中选中英文，按全局快捷键。
2. 工具保留当前来源应用的复制目标，执行复制并等待新文本，不先激活浮窗导致选区丢失。
3. 获取成功后，在鼠标所在屏幕附近显示浮窗，上方原文，下方译文区域显示加载状态。
4. 向配置的阿里云模型服务发送这次文本。译文可用后显示；支持流式逐步显示，未完成时保持明确的生成状态。
5. 用户可在窗口内滚动、选中文字或复制译文。
6. 点击窗口外任意区域，窗口立即消失；该次请求如仍在进行，取消本地等待并丢弃后续结果。

关闭后不能因为网络结果返回重新弹出。用户下一次触发时建立新的翻译会话。

## 功能要求

### F01 菜单栏与设置

- 工具可从菜单栏打开设置或退出，日常翻译不需要打开主窗口。
- 设置包含 API Key、模型名称、接口地址和全局快捷键。接口预设面向阿里云，具体地域和有效地址在接入前核对官方说明。
- 按用户 2026-11-08 最新要求，API Key、服务地址和模型保存在项目 `.env`，不使用系统钥匙串或系统偏好存储密钥。输入默认遮蔽；`.env` 不提交，示例文件不含真实密钥。重启后读取同一文件。
- 配置缺失或格式无效时提供明确引导，不发起无效翻译。只有文件保存成功才能显示保存成功；写入采用原子替换，失败保留原文件。
- 设置中简要说明选中文字会发送到配置的服务地址，以及复制操作会覆盖剪贴板。

### F02 全局快捷键

- 来源应用在前台时可触发；支持修改和保存快捷键。
- 注册失败或检测到冲突时明确提示，不显示已启用。更换失败时保留旧快捷键或明确告知当前不可用。
- 按住快捷键产生的重复按键事件不连续创建请求；主动再次触发时允许翻译新选区或重试同一文本。

### F03 获取选中文本

- 采用模拟 `⌘C` 和读取剪贴板的方式，不要求剪贴板内容恢复。
- 确认本次复制产生了新的可用文本。不能仅判断“剪贴板非空”，也不能仅以“文本不同于上次”判断成功；连续两次复制相同文本应可用。
- 空选区、无更新、纯空白或非文本内容不调用 API，不回退到旧剪贴板文本，显示“未获取到选中文字”等可理解提示。
- 权限缺失或被撤销时提示恢复步骤，不静默失败。复制等待有上限，不永久卡住。
- 原文保留段落结构；不在用户无操作时持续监视或上传剪贴板。

### F04 模型翻译

- 使用阿里云提供的 OpenAI 兼容聊天接口语义，配置包含服务地址、API Key 和模型名称，不要求依赖某个特定 SDK。
- 每次请求只携带翻译指令和本次文本，不携带之前会话的原文和译文。
- 翻译目标为简体中文，忠实保留含义、段落、编号、链接和必要术语，不额外问答或解释。待译文本中的指令也作为翻译材料，不作为应用指令执行。
- 处理正常返回、流式分片、流结束、错误响应和空结果；输出被截断或中途断流时不能标记完整成功。保留可读的部分结果并提示未完成。
- 模型和服务自身的额度、限速、上下文上限仍适用；工具不增加每日次数限制，不承诺免费或无限调用。
- 不静默重试并产生额外费用；失败后用户可主动重试。重试使用当前浮窗的原文，不擅自重读剪贴板。

### F05 原文译文浮窗

- 上方“原文”，下方“译文”；两部分清晰区分、可选择文字，长内容可滚动查看。
- 窗口显示在鼠标所在屏幕可见区域内，靠近屏幕边缘时调整位置，不越出屏幕而无法操作。
- 点击窗口内部、选中文字、滚动和点击复制译文不关闭窗口。复制译文后剪贴板为译文。
- 点击窗口外部，包括原应用、桌面或其他应用时，自动隐藏；尽可能保持该次点击对目标应用的正常作用，实际行为须真机验收。
- 关闭行为覆盖加载中、生成中、成功和失败状态。无需关闭按钮或 Esc 才能完成阅读流程。
- 窗口只在完成选区捕获后展示；不得让工具内的原文选区意外代替用户当前来源应用的选区。

### F06 并发与错误处理

- 任一时刻只保留一个当前翻译会话。新触发替换旧会话，取消旧请求并隔离已经返回或延迟到达的数据。
- 新选区不能与旧译文同时被展示成一组。关闭后结果不再更新界面，不自动重新打开窗口。
- 区分配置缺失、权限缺失、选区获取失败、网络错误、超时、鉴权失败、额度或限流、模型不可用、响应无效和结果不完整；提供与问题对应的下一步操作。
- 取消本地请求不能保证服务端停止计费；不把“窗口关闭”解释为费用撤销。

## 模块职责和接口约定

以下定义模块边界，不绑定语言或框架；具体类型和函数签名在相应 Task 编码前确定。

| 模块 | 输入与输出契约 | 责任边界 |
| --- | --- | --- |
| 快捷键与选区获取 | 触发事件 → 本次文本与来源信息，或明确失败原因 | 负责系统权限和复制结果，不调用模型 |
| 翻译会话协调 | 新文本、关闭、重试 → 会话状态及唯一请求标识 | 负责取消、最新请求生效和界面状态 |
| 模型客户端 | 文本、目标语言、配置快照 → 文本片段、完成或错误 | 负责兼容协议、超时和解析，不控制窗口 |
| 浮窗 | 当前会话状态 → 展示；输出关闭、复制、重试事件 | 负责显示与交互，不直接读取凭据 |
| 配置与凭据 | 读取或保存设置 → 有效配置或错误 | 访问项目 `.env`，不输出密钥日志 |

会话状态至少区分：获取选区、翻译中、完成、失败和关闭。部分译文附属于翻译中或失败状态。捕获或请求结果必须关联对应会话，过期结果无论成功或失败都不得更新当前界面。

## 性能 隐私与恢复

- 网络、复制等待和解析不得阻塞界面；关闭操作不等待请求结束。
- 开发初始建议值：复制等待上限 1 秒，获取文本后 300 毫秒内显示加载状态；首个有效译文片段等待上限 30 秒，片段间无进展上限 30 秒，单次总时长上限 120 秒。以上为待真机测量的实现目标，不是已有性能结论；调整须在任务记录说明。
- 不静默截断原文。超出本地安全上限或模型上下文限制时，提示缩短选区；具体输入上限随模型接入确定并记录。首版不自动拆分多次计费请求。
- 使用 HTTPS 发送请求；API Key 只发送给当前配置的服务地址。错误提示和日志不得回显完整密钥、认证头或原文译文。
- 不保存翻译历史；关闭窗口后清理不再需要的会话引用。剪贴板由用户明确接受覆盖，不将其恢复为旧内容。
- 网络失败不丢失当前浮窗原文，支持主动重试；重启后恢复设置，不恢复上次翻译内容。

## 验收用例

下列均为待执行用例，不表示功能已经通过。实现任务必须记录实际环境、应用版本、结果和证据。

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| A01 | 首次配置与重启 | 保存有效配置后重启可读取；Key 仅在被忽略的 `.env` 保存，不写系统凭据或日志；存储失败准确提示 |
| A02 | 正常跨应用翻译 | 在浏览器、系统文本编辑器和可选中文本的 PDF 阅读器各选取英文，快捷键得到对应原文与真实 API 译文 |
| A03 | 剪贴板已有旧内容但无选区 | 不翻译旧内容，不发送请求，提示获取失败 |
| A04 | 连续复制相同英文 | 两次有效复制均可触发；不因文本相同误判失败 |
| A05 | 权限拒绝与撤销 | 给出可操作引导；恢复权限后重新触发成功 |
| A06 | 快捷键更换与注册失败 | 设置状态与实际注册一致；按住一次不发起多次请求 |
| A07 | 长文本与显示边界 | 段落保留、窗口可滚动；屏幕边缘和实际多屏环境不出现不可访问内容；超限不静默截断 |
| A08 | 窗口内部操作 | 点击、选择文字、滚动、复制译文均不关闭，复制结果正确 |
| A09 | 点击外部关闭 | 加载、流式生成、完成、失败四种状态下，点击外部均关闭；后续网络结果不重新弹出 |
| A10 | 连续选择 A 与 B | 即使 A 晚返回，也始终只有 B 的原文和译文配对，旧错误不覆盖 B |
| A11 | 网络与服务失败 | 覆盖断网、超时、鉴权、限流或额度、模型无效、空结果；不显示为成功且不静默重试 |
| A12 | 流式中断与截断 | 中断、异常结束、分片边界及截断可识别，部分译文明确标记未完成 |
| A13 | 翻译质量 | 单句、段落、技术文字和含指令句子的原文得到中文翻译，保留结构，不按原文指令执行其他操作 |
| A14 | 隐私与空闲行为 | 无操作时不读传剪贴板，无历史文件，日志无密钥及原译文；退出后快捷键和事件监听释放 |
| A15 | 真实服务与使用次数 | 用户真实阿里 API 配置完成端到端翻译；无应用自行设置的每日次数拦截，服务限制正常提示 |

兼容性验证至少记录上述三类应用的具体名称、版本、macOS 版本和芯片。应用尚未安装或没有所需设备时记录未执行，不能填为通过。发现特殊应用复制行为时记录限制和后续 Fix；不静默缩小产品目标。
