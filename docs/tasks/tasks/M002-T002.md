## 目标和范围

用户在其他应用中选中英文、按快捷键，即可在鼠标附近的浮窗对照原文和中文译文，点击浮窗外关闭。将快捷键、复制、网络翻译和窗口交互作为一个可用流程交付。

包含 F02—F06、F01 的快捷键设置，覆盖 A02—A13、A15 以及 A14 的运行行为，并回归 A01。技术方向沿用 M002：系统热键、CGEvent、NSPasteboard、URLSession、Swift 并发、AppKit 浮窗和 SwiftUI 内容。

不包含 OCR、截图、历史记录、多引擎、语音、服务端和公开分发。未完成的翻译流程不作为可用功能合入主分支。

## 接口和状态约定

具体 Swift 类型与方法在编码前落实；以下行为必须保留。

| 边界 | 输入和输出 | 关键约束 |
| --- | --- | --- |
| 快捷键注册 | 按键与修饰键 → 注册成功或失败 | 支持释放与替换；注册失败不得显示已启用；按住不重复发送 |
| 选区捕获 | 会话标识、来源应用 → 本次文本或获取错误 | 捕获前不抢焦点；复制超时、权限、无更新、非文本明确区分 |
| 模型客户端 | 请求标识、文本、配置快照 → 译文增量、完成或错误 | OpenAI 兼容聊天格式；单次请求无历史上下文；可取消 |
| 会话协调 | 触发、重试、关闭、异步结果 → 当前会话状态 | 旧会话结果全部丢弃，包含复制结果、译文和错误 |
| 浮窗 | 状态与原译文 → 关闭、复制、重试事件 | 点击内部不关闭；点击外部立即隐藏；UI 不直接读取密钥 |

状态至少包括获取选区、翻译中、完成、失败、关闭；部分结果属于生成中或失败状态。新的触发先使旧会话失效，再开始捕获。关闭使当前会话失效并取消本地等待，网络迟到结果不能重新弹窗。配置保存只影响之后的新请求。

手动重试使用当前浮窗保存的原文；不偷偷读取新剪贴板。所有日志对 Key、认证头、原文和译文保密，测试夹具只使用公开或人工编写的示例。

## 实施内容与验收

1. 注册可配置的全局快捷键，保存与实际注册结果一致；验证冲突、更换失败、按键重复和退出释放。确定默认组合并记录选择理由。
2. 模拟复制，等待本次剪贴板更新，再读取可用文本。允许覆盖旧剪贴板，不恢复；不能仅凭文本相同与否判定成功。无更新时禁止翻译旧值，权限缺失时给出操作引导。
3. 核对所用阿里地域、接口与模型，采用兼容请求格式及流式响应。使用 URLSession，处理分片、流结束、空结果、错误、超时和取消，不静默重试或截断输入。
4. 在鼠标所在屏幕显示原文与译文；长内容可滚动，屏幕边缘调整窗口位置。内部复制和选择文字不关闭，复制译文覆盖剪贴板。
5. 在加载、生成、成功、失败状态下点击窗口外均关闭；迟到结果不能重新打开。外部点击仍应作用于原目标；若系统行为不满足，记录并修复，不能仅以窗口消失判断通过。
6. 验证新旧会话交错返回、旧错误晚到、关闭后返回、重试与配置更新。界面不出现 B 原文配 A 译文。
7. 明确输入长度上限和超时策略，记录真实测量。需求中的初始时间参数是待验证目标，调整须说明理由，不把未测量值写成实测性能。

关键验收以 [A02—A15](../../testing/M002.md) 对应条目为准。T002 合并前须在浏览器、文本编辑器和文本型 PDF 阅读器完成真实选区与翻译，并验证核心失败与关闭行为。测试替身通过不代表真实 API 通过。

## 风险核查

- 核查来源应用无选区时 `⌘C` 的实际行为；若应用会复制整行或其他内容，剪贴板更新本身不足以证明有选区。记录实例和处理方式，不能将其误写成“无选区已可靠识别”。影响验收时解决或明确提出范围问题，不静默放宽 A03。
- 验证快捷键修饰键仍按下、复制尚未完成时切换应用、连续触发等时序，避免读错来源。
- 选区捕获失败时仍须提供错误反馈；原译文浮窗只在有效捕获后建立，不能显示旧原文冒充本次结果。
- 权限的授权与撤销、浮窗焦点和多屏行为必须真机验证。缺 API Key 或设备只能记录未执行，不填造结果。

## 验证计划

- 单元：复制结果判定、同文重复制、输入长度、状态转移、会话失效、重试原文固定、错误映射。
- 集成：用可控网络响应验证分片边界、异常结束、截断、取消和超时；真实系统适配另行测试。
- 整体流程：真实应用 → 快捷键 → 阿里 API → 原译文对照 → 点击外部关闭；至少三类应用。
- 边界异常：A03—A12 全部覆盖；特别测试旧复制结果和旧网络错误不能影响新会话。
- 回归：T001 配置、密钥存储和退出行为；A13 翻译样例与 A14 隐私、资源释放。
- 覆盖率：单独报告解析、协调和校验规则范围；不能因总覆盖率达标而豁免关键流程。
