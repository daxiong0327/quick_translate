## 目标和范围

交付能在用户本机使用的 `.app` 产物、使用说明和可信的验收记录，证明从构建到实际打开后的完整翻译流程可用。

包含：按实际工程构建可运行应用，记录本地签名与运行方式，完善安装或放置、首次配置、权限、快捷键、错误恢复、更新和退出说明，执行最终兼容性和回归验收。

不包含：上传应用商店、远程发布、付费开发者计划、公开签名公证、自动更新或后台服务部署。实际复制到系统应用目录或替换已安装版本需依据当时的用户授权，不能因产物构建成功就声称安装完成。

- 证据：记录 A01—A15 的环境、方法、结果、证据位置；不保存用户敏感原文、译文或 Key。

## 验收条件

1. 使用记录中的命令从已确认提交构建产物；在实际运行位置启动，并验证菜单栏、配置和退出。
2. 用非敏感样例完成真实 API 翻译，点击外部关闭，下一次翻译仍正常；网络失败后可恢复使用。
3. 浏览器、系统文本编辑器、文本型 PDF 阅读器逐项记录真实应用版本与结果。验证长文本、边缘窗口和多屏环境，不把单屏通过外推为多屏通过。
4. 最终运行产物的权限、凭据访问与设置保持正确；开发调试环境的成功不能代替本地交付产物的验证。
5. A01—A15 全部有通过证据；必要项目未执行或失败时不关闭 M002。已发现的特殊应用限制必须可见，并按既定兼容目标处理，不静默缩小范围。
6. 文档与实际版本一致，无密钥或用户数据，所有必要 Task 和 Fix 已合并后完成 M002 总体验收。

- 单元：使用现有工程测试，按最终改动影响范围执行；本任务没有业务变更时不新增复述实现的测试。

- 边界异常：以实际运行产物验证权限恢复、网络恢复、连续触发、关闭后返回和长文本，复用已有效覆盖且对应同一代码版本的证据。
